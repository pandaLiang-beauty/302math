# 真题与880对应关系

当前发布：1,016 条关系，覆盖 929 道880（全部文本题）、2020—2026 年全部155道真题，另有16道2008—2019年真题作为更贴近的对应题。

每条关系注明同法练习、变式检验或基础衔接。基础衔接只表示具体步骤或前置技能的联系，不表示整题解法相同。多小问题可以按小问建立联系。880卡片的“对应真题”支持反向定位到原题。

`relations.json`保留原301条关系；`coverage-links.tsv`是逐题补充清单。清单每行为：真题ID、明确列出的880题ID、关系类型、共同技能、对应说明，以竖线分隔。不存在按关键词自动兜底的分配。

发布入口：

```
python scripts/publish_relations.py --build
python scripts/publish_relations.py --apply
```

构建生成`complete-relations.json`，校验所有880与近七年真题均有关系、无重复、题面哈希一致；已有关系优先保留。仅导入关系表，不修改参考答案或学习记录。导入前应在线备份生产数据库，禁止用测试库替换生产库。旧`publish_exam_links.py`同时涉及答案，不用于这次关系发布；以后若重建原始关系，须重新运行上述构建和校验。

验证包括覆盖率、过期题面拒绝及事务回滚、学习记录与参考答案保留、反向查询过滤，以及浏览器中的分组和新旧年份双向跳转。覆盖率表示每题有明确连接，不等同于每题都有整题同法题。

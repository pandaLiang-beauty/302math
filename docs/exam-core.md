## 学习流程

- 首页按 2020—2026 年组织核心套卷，提供继续上次套卷、已开始和已复盘数量；其他年份仍可进入。
- 选择、填空与大题答案，以及文字演算，自动写入服务器。选择题有确定参考选项时核对客观正误；题面或参考答案存在已知疑点时标注说明并停用自动判分；主观题对照解析后自评，未引入运行时 AI 批改或强制复习排程。
- 解析直接在本题下面展开。每道核心真题都能进入同法补练；关联理由说明共同的具体操作及涉及的小问，区分同法练习和变式检验。没有合适关联时保留空列表。
- 补练保留来源真题、回到原题的链接。章节练习仍可自主选择，不冒充针对原题的同法推荐。
- “完成核对”保存不可修改的当次答案、演算、自评、错因及当时的草稿照片引用。“再做一次”建立新的尝试，旧记录从历次作答查看。题目笔记仍按题汇总。

## 保存机制

`study_sessions` 标识套卷或补练上下文；`study_items` 存当前尝试；`study_history` 保留已完成尝试的快照。重复写请求使用 mutation 去重，revision 防止其他页面的旧内容覆盖新内容。同题的本机请求串行发送。

浏览器 localStorage 只用来保存待同步输入和旧版本备份。未同步内容可下载；网络恢复或点击重试后再次发送。页面显示“已保存到服务器”才代表服务器已确认。断网不能首次加载题目；已经打开页面的输入可以暂存。

打开主站时迁移旧的 `math302-paper-choices-v1`。仅填入尚无记录的真题答案；服务器已有不同内容时保留两份，不覆盖，首页提供提示及本机导出。原始本地键不删除。

正式笔记和照片沿用独立接口；照片明确删除后，历史中的引用可能失效。学习记录 JSON 导出包含记录与照片索引；完整照片文件由原有服务器备份保存。

`workbook_text` 保存原始 Markdown、来源及内容指纹，前端用现有 Markdown/KaTeX 显示。题目正文不依赖整题截图。

逐题解析在离线流程中结合答案册扫描页整理，记录所用页码及原题疑点；再独立复算，初稿未经复核不能打包上线。`source_verified` 是整理流程的源文核对标记，不代表逐字人工审核。不能对应原书的补充推导在页面明确区别，不能伪称原书解析。内容已固化，用户点开解析时不会现场调用模型。

核心真题原有的选择题只有答案字母。新增 `exam_explanations` 补充逐题讲解，按实际排版读取公式，经过独立复算；原有填空与解答题解析继续使用。

关联题经过候选阅读、独立配对审核，以及对照实际真题排版的再次审核。两轮都需检查具体共同解法；不是按词频或知识点标签直接补满题数。关系保存原题正文与选项、练习题正文与选项的指纹，内容变化后旧关系自动失效。重新发布时按来源真题完整替换配对集合，明确为空时删除旧配对。

离线工作区 `backend/data/authoring/` 包含扫描页、逐题结果、过程日志。成品为 `content/solutions.json`、`content/exam-solutions.json`、`content/relations.json`，审核记录及来源清单一并保留，不在运行时依赖题间或 408。已确认的转写错误在 `content/transcription-corrections.json` 单独记录，原上传文件保持原样。
